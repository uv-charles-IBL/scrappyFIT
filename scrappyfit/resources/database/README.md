# Vendored atomic database

A self-contained copy of the data files scrappyFIT needs, so an install works
on a machine with no GeoPIXE present — including off a flash drive.

Eleven files are unmodified copies from CSIRO's open-source GeoPIXE
(MIT, Copyright (c) 2023 CSIRO; licence text in `dat/LICENSE-CSIRO-GeoPIXE`):
`ElamDB12.txt`, `xray_lines.txt`, `xsect_K/L/M.txt`, `proton.txt`, `alpha.txt`,
`hubbell.dat`, `edge.txt`, `mass.txt`, `element.txt`. The `MAC_*` tables and
the two extra line tables were produced for scrappyFIT. The source and licence
of every file is listed in `THIRD_PARTY_NOTICES.md` at the repository root.

| file | what it is |
|---|---|
| `ElamDB12.txt` | Elam, Ravel & Sieber 2002 — edges, subshell fluorescence yields, Coster-Kronig factors, subshell-resolved line branching |
| `xray_lines.txt` | GeoPIXE's flat line table. **Contains fabricated L values** for Ca, Sc, Ti, V — see the manual |
| `xray_lines_rebuilt.txt` | the same table with L and M rebuilt from xraylib. K lines bit-identical. **The default** |
| `xray_lines_light.txt` | Li, Be, B supplement |
| `xsect_K/L/M.txt` | proton ionisation cross sections |
| `proton.txt` | Andersen-Ziegler stopping powers |
| `hubbell.dat` | Berger & Hubbell — this *is* the XCOM dataset |
| `MAC_Henke1993.txt` | CXRO f2, 10 eV – 30 keV |
| `MAC_SabbatucciSalvat2016.txt` | 1 keV up. **Unusable for light elements** |
| `MAC_FFAST.txt` | Chantler, generated by `tools/make_ffast.py` |
| `edge.txt`, `mass.txt`, `element.txt` | edge energies, atomic masses, symbols |

Regenerate the two derived files with `tools/make_ffast.py` and
`tools/rebuild_lines.py`.
